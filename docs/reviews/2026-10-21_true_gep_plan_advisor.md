2026-10-21. Read: GOAL.md, MultiTypedGEP.md rev 4, Rules.md, the plan, the safety-layer plan, WGSL_COVERAGE.md, WGSL_TYPED_GENE.md, `check.rs`, `safety.rs`, `gen_tables.py` and its rows, `wgsl_fit.rs`, `knob::check_legal_under`.

## 1. Does the plan deliver the goal?

Partly. The approach is right, and the rung types (`L<d>`/`C<d>`/`B<d>`/`O<d>`), masked index duals, origin/offset duals and bound duals already carry most of layers 2, 3, 4 and 6 for the Gram interface. Four things in the kingdom today leave a rule judged after expression; the plan names none:

1. **Generic interface stores take `u32.index`** (`render.rs:738`, `store.<binding>_<rung>`: `[u32.index, value]`). Only the Gram `h` store takes `u32.cell`. For every V24 interface (E1's real problem) write-set disjointness is layer 7's Fourier-Motzkin proof after expression. D1 does not say how an arbitrary binding gets an owned-cell dual. This is the hard rule and the critical path.
2. **Two escape rows make uniformity a post-expression judgement**: `uflag.of_flag` (F1728, "uniform when the checker's layer 4 proves it") and `uniform.of_checked` (F1729). While they exist `u32.uniform` and `bool.uflag` are not types: a random gene puts a thread id under them and a barrier follows. Delete both.
3. **Layer 5 (adapter) is absent from the plan.** Workgroup memory over 32 KB (the `wg.decls` knobs sum freely), workgroup size, and feature rows (subgroups, f16) on a target without them are judged after expression. Fix: the alphabet is per `(interface, contract, target)`, and `wg.decls` rows are generated as the complete set of declarations within the budget.
4. **"Fitness runs every expressed kernel" meets the GPU.** The cost estimator (`render.rs:3246`) refuses before dispatch and a runaway is drained; A1 must list both. A legal gene can hold the item loop (2^16 under the contract) inside four nested `lit64` tile loops: 2^40 iterations, a Metal hang that survives the process. The type must carry a work budget (§2, bounded loops).

## 2. A type construction for each rule

**In-range indexing.** Workgroup and private arrays: already types (`wgindex`, `wgvindex`, `wgaindex`, `pindex`/`pindex16`/`pindex128`: the row spells `i & (len-1)` or `i % len`). Keep one index dual per array length; retire `wg.get`/`wg.set` (unsafe rows masking to 2,047 whatever the length) from the safe alphabet. Storage arrays: reads at any index are defined by naga's `Restrict` clamp (wgpu bounds checks), so a read needs no type; a store's index is covered by ownership below (a clamped store lands on the last element, another invocation's).

**Write ownership and write-set disjointness (the hard one).** Make the owned cell a type per output binding, generated from the dispatch contract, not proved from the index: for binding `b` with element count `n_b` and the dispatch's thread coordinates, a dual `u32.own_b` with exactly these producers: `own_b.of_thread(gid-axis, blk)`: `t * blk`, `own_b.plus(own_b_base, lit64)`: `base + min(i, blk-1)`, `own_b.plus_tile(own_b_base, tcounter_d)`, the strided/grouped forms the Gram rows already have, and a guard `own_b.in_range` that the store row spells as `if (idx < arrayLength(b))`. Store rows: `store.b_<rung>: [u32.own_b, value]`. The offset rows take an **origin** dual (`own_b_base`), never another offset (the rule the rowbase duals already enforce), so the sum stays inside the thread's block. Every expressed tree then writes `thread_base + bounded_offset` with disjoint blocks by construction: disjointness is a property of the row set and the contract, proved once per generated table (a test enumerates every invocation's writes at the contract's smallest shapes). Restriction: a thread writes a contiguous, strided or grouped block of one binding, indexed by one or two thread axes; no data-dependent, hashed, `/`- or `%`-derived store indices; no two store forms on one binding (the mirror pair stays a declared form with its own dual, as `u32.mirror` is). Cost: scatter kernels (histogram, compaction, sort) are spelled only through atomics, and a transposed write needs its own declared form. Layer 7's Revision-1 proof already pays this price (non-affine indices illegal).

**Read-after-write and aliasing.** Loads of an output binding take `u32.own_b` only (as `load.h_safe` takes `u32.cell`); reads of another invocation's output happen across dispatches, declared in the problem's dispatch program (ping-pong). Workgroup memory: phase typing. A block rung gets a workgroup-phase row `wg.phase_L<d>: [block.W<d>, block.R<d>] -> stmt.L<d>` rendered `{stores} workgroupBarrier(); {reads} workgroupBarrier();`. In a `W<d>` block, `wg.set_*` takes `u32.wgown` (`lidx + k * threads`, already a dual) and no `wg.get_*` of a foreign index exists; in an `R<d>` block, `wg.get_*` takes any masked index and no `wg.set_*` exists. Atomics stay free anywhere (race-free; `exchange` is order-dependent and goes out of the deterministic alphabet). Cost: a read-modify-write of a foreign element within one phase is unspellable.

**Barrier and subgroup uniformity.** Carried by the rungs once the two escape rows go. Add: `u32.uniform` producers stay cfg fields, `wid`, `nwg`, subgroup size and count, literals, and counters of loops bounded by `boundu`; `uniform.of_tcounter<d>` must be split so a counter of a `tilex_C` loop (bound `boundx`, divergent) has no uniform producer. Subgroup collectives become statement rows at `L` rungs writing a register (`stmt.subgroup_sum_L<d>: [reg, value]`), not value rows, so an expression under a `C` rung cannot hold one. Cost: a subgroup result passes through a register.

**Bounded loops.** Already types (`boundm/d/rows`, `lit64`, `lit4096`, `boundu`, `boundx` capped at 2^24 by the row's text). Two gaps: `reg.get_i -> xbound` lets the body change the bound (`loop_bound_changes_in_body`): render every bound row as a `let` hoisted before the loop, so the trip count is fixed at entry whatever the body does; and the work budget: type the tile literal by depth (`lit64` at depth 1, `lit16` at depth 2, `lit4` at depths 3-5), so the product of every nest is at most 2^16 × 64 × 16 × 4^3 = 2^32 under the contract, and the item loop's `boundx` cap becomes the contract's `m`. Cost: a 64-wide inner loop three deep is unspellable.

**Defined arithmetic.** WGSL facts first: integer overflow wraps, `x / 0 = x`, `x % 0 = 0`, runtime shift amounts are taken modulo 32, float division by zero is IEEE. All defined; the rule is only (a) no wrap landing in a store cell or a loop bound, and (b) no overflow in a constant expression (a naga shader-creation error: `1u << 40u`, a product of literals). Construction: a width lattice on index values, `u32.i<k>` (value below 2^k, k in 8, 16, 24, 32): `add: i<k> x i<k> -> i<k+1>`, `mul: i<a> x i<b> -> i<a+b>`, no row past `i<32>`; thread axes and cfg fields typed by the contract's ranges (`gid.x < 2^16`, `cfg.d <= 8192 -> i<13>`); `and`, `min`, `%`, `>>` narrow back. The owned-cell and bound duals accept only lattice members, so no expressed cell or bound wraps, and literal-only subtrees cannot overflow because literals enter the lattice at their width. Elsewhere plain `u32.index` arithmetic may wrap (a wrong value, legal), which retires `index_wraps` as a fault. Cost: long index chains must pass a narrowing row.

- **A0 (new): delete `uflag.of_flag`, `uniform.of_checked`, `wg.get`/`wg.set` and the unsafe-kingdom rows unreachable from `kernel.safe`** from the safe alphabet, before A2, so the measurement is of the kingdom the plan will keep.

- **Work-budget task missing** (the GPU hang is the one failure fitness cannot score).
- **E1's seeds.** 29 of 32 V24 seeds read today; stronger types will read fewer. Add a task: every E1 seed reads into the typed kingdom or the kingdom is widened by a type, and the three unread are named; the closure test runs on the seeds' interfaces, not only on `v24_ingest5b`'s.
- **The contract is an input to the types.** C1 and the alphabet must be per `(interface, contract, target)`; the plan says "per interface".
- **A1 must list the cost estimator and the runaway drain** as judgements.
- Shortcut risk: C2 says "removed or moved to a test". A judgement moved to a test that still runs in `wgsl_fit`'s loop under a flag is a filter. C2's gate should be "no call from the evolution binary into `check.rs`, `safety.rs`, `knob::check_legal_under` or the cost estimator".

## 4. What changes or weakens the goal

- **C4 contradicts the goal as written.** Naga accepts racy and unbounded kernels; a kingdom whose types describe exactly the legal kernels cannot spell them. Restate C4: every naga-valid kernel that obeys the legality rules reads; one outside them goes in REFUSED.md under a new class "outside the typed kingdom by design", not as a reader bug.
- **The infeasible band stays.** `wgsl_fit.rs` scores a kernel that fails a layer at `INFEASIBLE_FLOOR + ...`. After C2 the band must be for measured wrongness only (cases failed), never for a layer verdict; the plan should say so, or the filter returns as a fitness term.
- **Decision 2 (the range-check patch)** is a checker change; harmless as a test oracle, but it must not be applied as a filter in the meantime.
- The unique-feature sentence promises "a safe GPU program is reachable from any gene". True with ownership as a type; false if layer 7 is kept for the generic interfaces. The plan must say which.
