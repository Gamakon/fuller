# Codex review of the true multi-typed GEP plan for WGSL, 2026-10-21

1. **Blocker — the plan cannot meet the goal while retaining C4.** `C4` requires reading *every* naga-valid compute kernel, while the goal permits only kernels legal by the symbol table. Naga-valid WGSL includes unbounded loops, races, non-injective stores, arbitrary aliases, and target-incompatible features. The coverage document already excludes unbounded `while` from the safe kingdom. This is a direct specification conflict, not a gap to test around. Replace C4 with “every kernel legal under the declared target/interface/dispatch contract reads into its corresponding typed kingdom.”

2. **Blocker — the plan leaves contract-dependent legality outside expression.** Today, `check()` runs seven post-expression layers, including rendering/parsing then whole-module safety analysis under a `Contract`; it judges aliasing, global write sets, ordering, and target properties after expression. C2 removes these calls from evolution, but no B-task requires replacing their inputs with an interface/target/contract-indexed kingdom. Thus C2 could merely remove the last protection. The symbol table must be instantiated as `K<target, interface, dispatch-contract, alias-partition>` before initialization; host validation of that external contract is acceptable, but is not a gene filter.

3. **High — D1’s mandatory scope is too weak and B1..Bn is underspecified.** D1 says “at least” five items, omitting subgroup uniformity, private/workgroup range, workgroup ordering, loop-body mutation, aggregate loop work, target limits, atomic determinism, and aliasing. 5. **Required constructions and expressiveness costs:**

| Rule | Required duals/rows | Cost |
|---|---|---|
| Array range | `Array<B,E>` and `Idx<B>`; only range-preserving rows (`zero`, `succ_lt`, `clamp_lt`, proven affine offsets); accesses consume matching `Idx<B>`. | One family per binding/length class; raw indexing disappears. |
| Write ownership / per-output disjointness | `Own<out,region>` capability derived only from injective invocation maps; stores consume it. Sequence rows carry effect rows `Writes<out,region>` and only compose statically disjoint regions. Output loads take `Own` only. | Rejects arbitrary/non-affine stores and requires finite approved region/map templates. |
| Workgroup races / RAW | `WgOwn<A,epoch>` for writes; `WgRead<A,epoch+1>` produced only by barrier rows; no raw `wgindex` setter. | Duplicates statement/block rows by phase; excludes unsynchronised sharing. |
| Barrier and subgroup uniformity | Context-indexed `Val<T,WgUniform>` / `Val<T,SubgroupUniform>` and `Block<ctx>`; barriers and subgroup rows require their context. Delete `uflag.of_flag` and `uniform.of_checked`. | Duplicates value/operation rows by provenance; fewer data-dependent controls. |
| Bounded loops / work budget | `Bound<k>` plus immutable snapshot rows; loop body type carries `Fuel<n>` and nesting consumes a fixed total budget. | Finite bound/budget strata; no arbitrary dynamic or multiplicative nesting. |
| Wrap | Contract-bounded `U32<lo,hi>` refinements; `add_ok`, `mul_ok`, `shl_ok` exist only when resulting interval fits. | Range-type proliferation; rejects otherwise valid modulo arithmetic. |
| Division | `NonZeroU32` (and signed `DivisorI32` excluding `-1` with `MIN` dividend); `div/mod` require it. | Requires positive literals, `+1`, or explicit safe constructors. |
| Shifts | `ShiftCount<0..31>` (or a row whose declared semantics is explicit masking, not renderer repair). | Conversions/32 refinements; arbitrary counts need a deliberate safe constructor. |
| Target limits | `K<Target>` filters feature rows; `WgSize<target>` and `WgMem<target,bytes>` compose declarations only within limits. | Per-target tables/resource strata. |
| Aliasing | Contract-indexed `Binding<range,alias-class>`; only declared disjoint bindings coexist, and reads/writes require compatible capabilities. | The caller must supply validated ranges; arbitrary overlapping bindings are excluded. |

6. **High — current bypass rows prove uniformity is still judged after expression.** `uflag.of_flag` and `uniform.of_checked` explicitly claim validity “when the checker proves it”; they allow divergent values to masquerade as uniform. Subgroup operations also lack a subgroup-uniform context. These must be removed or split into provenance-preserving rows before checker removal.

7. **Order correction.** Build contract/target-indexed roots and range/ownership/effect contexts first; then all dependent rows (arrays, stores, barriers, loops); then typed frames and shared operators; finally C1/C2. Measuring A2 first is useful, but “one rule per commit” cannot independently solve interacting write/range/uniform/resource facts. Also make C1 test actual typed initialization and every shared-core operator, while asserting no renderer rewrite or checker decision is invoked—not just zero checker failures.
