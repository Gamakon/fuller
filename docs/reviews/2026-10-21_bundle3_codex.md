# Codex review, bundle 3 (WGSL fallback removal, clamp guard, fold landing, retype retry, scratch reuse), 2026-10-21

1. **High — fold pass can replace a varying expression with a bogus constant.** `constant_on` treats relative variation up to `1e-12 × magnitude` as “one value”; the new ancestor climb applies that approximation to arbitrary parents. For `(Add (Var "x_0") (ProtectedAcos (Num 2)))` on rows `x_0=1e12` and `1e12+1`, `Acos(2)` folds to `0`, then the root range `1` passes the `<= 1` threshold and is replaced by `1000000000000.5`, changing both outputs by `0.5`. This contradicts the stated “one constant on every row” guarantee. `fuller/src/clamp.rs:62`, `fuller/src/clamp.rs:99-104`.

2. **High — the removed fallback is still silently replaced in the Karva masking test path.** A wrong-typed href, unknown variable, raw number, wrong payload row, or unrecognised application is converted to `terminal_leaf(demand)` rather than reported. For example, an f32 operand containing `@0` whose referenced gene has a u32 root becomes an arbitrary f32 own/const/literal/first-terminal row. This directly defeats the no-substitution invariant and makes the randomized test certify repaired chromosomes instead of detecting bad ones. `fuller/src/wgsl/safe_karva.rs:1471-1489`.

3. **Medium — renderer’s alleged `own_or_bug` path chooses arbitrary stand-ins.** On an absent/filtered output row, `own_or_bug` calls `terminal_leaf`, which deliberately falls through from `own.*` to `const.*`, `literal.*`, then the first terminal row. Thus a missing own terminal can become a register/builtin/counter rather than producing the required named defect. The `own.missing` error sentinel is reached only when even that substitution fails. `fuller/src/wgsl/render.rs:38-65`, `fuller/src/wgsl/render.rs:4324-4330`.

4. **Medium — clamp reporting fails open, making a broken checker look like an unflagged result.** Missing executable, nonzero exit, malformed output, timeout, parse failure, or an emitted `CLAMP_ERROR` all return empty fields; scoring then treats them as not `yes`. A normal run without `target/release/examples/clamp_check` therefore produces a complete results table with no clamp verdicts and no failure. `phylu/scripts/srbench_tf_run.py:188-201`.

5. **Medium — the new clamp gate can pass using a stale release binary.** `test_clamp_flags.py` invokes `target/release/examples/clamp_check` directly and neither builds it nor verifies its source/version. After modifying `fuller::clamp`, an old binary can validate the historical expected four laws while testing none of the changed code. `phylu/scripts/test_clamp_flags.py:18-27`.
