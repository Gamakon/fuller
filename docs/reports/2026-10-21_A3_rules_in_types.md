# A3: which WGSL legality rules the safewgsl kingdom's types already carry (2026-10-21)

**Context.** Task A3 of `docs/PLAN_true_gep_wgsl.md` (true multi-typed GEP for WGSL, `nucleotable/docs/MultiTypedGEP.md` rev 4, `docs/GOAL.md`): analysis only, no code change, no build, no GPU. Question: for every legality layer and reason of `src/wgsl/check.rs` (layers 1-7, plus the rule names of `src/wgsl/safety.rs` that layer 7 returns) and every rule of `docs/PLAN_general_safety_layer.md`, does the symbol table's type structure (`kingdoms/safewgsl/types.tsv`, `functions.tsv`, generated by `gen_tables.py`) already make every expressed tree obey it, or is it still judged after expression, or made true only by the renderer? Sources read: `kingdoms/safewgsl/{TYPES.md,types.tsv,functions.tsv,gen_tables.py,README.md}`, `docs/kingdom/WGSL_COVERAGE.md`, `docs/PLAN_general_safety_layer.md`, `src/wgsl/check.rs`, the rule names of `src/wgsl/safety.rs`, and the renderer spots named below. Not measured here: A2 measures which rules fail on random genes; this report says which rules the structure can or cannot guarantee.

**Reading key.** YES = the rule holds for every tree the table can spell, by dual and row structure alone. PARTLY = holds for the forms the types cover, and a named row or form leaves a hole. RENDERER = the rule holds only because `render.rs` rewrites the text (a mask, a `max(b,1u)`, a clamp), so the type does not say it; for true GEP this is a hidden repair and belongs in the types. NO = a spellable tree breaks it.

Two facts that apply to every row of the table:

1. Today's gene expression is not yet multi-typed: `types.tsv` carries `fallback`, `fallback_bits`, `fallback_noop`, `fallback_elem` columns (for example `store.store` fallback "no-op, codon masked"; `kernel` "an empty kernel"), and `render::own_leaf` / `own_or_bug` substitute the thread's own row, column or cell when a slot is mistyped. Rev 4 forbids any fallback. Layers 1 and 2 are therefore YES only once the per-type frames of rev 4 replace the projection; the 68 `own.*` rows (functions.tsv class `own`) are the terminals that give each rung, index and statement dual a leaf for its tail.
2. The kingdom is the *Gram role plus declared interfaces*: `load.phi_safe`, `load.h_safe`, `store.h_*` are role rows; the generic `load.buffer` / `store.buffer` (F007, F195) take any `u32.index`. Where a rule is YES for `h` it is NO for a generic buffer.

## Summary

**Carried by the types today (YES):** root and signature typing once frames replace fallbacks (1.1, 2.1 root); barrier never under a conditional (2.2); bounded loop constructors, no nested item loop, tile depth <= 4 (2.3); break and continue placement (2.4, 2.5); the thread's own `h` cell for stores and reads on the Gram role (2.6, 7.2, 7.4, 7.8); non-wrapping difference and shift (3.4, in part); barrier uniformity through `uniform`, `uflag`, `boundu` vs `boundx` (4.1 through the typed path); conditional `return` (4.2); loop counters and conditions produced only by the loop rows (6.1 for literal and uniform bounds); workgroup puts with `wgown` (7.5, in part); atomic range and race-freedom (7.6).

**Not carried (NO or RENDERER):**
- Bypass rows that undo typing: `uflag.of_flag` (F1728), `uniform.of_checked` (F1729).
- Store ownership of a generic buffer (7.1) and loads of a written buffer (7.4); the write-set proof rests on `safety.rs`.
- Workgroup-array race freedom for `wg.set` over `wgindex` and for read-after-write without a barrier (7.5).
- Subgroup operations in uniform control (4.3).
- Index range for workgroup arrays by the renderer's length-mask (3.1); private-array dual vs length (3.2); input buffer reads (3.3).
- Wrap of `index.add` / `index.mul` and of loop strides near `u32::MAX` (3.4, 6.2), which depend on dispatch ranges.
- Division and modulo guards, done by the renderer (8.1).
- Loop bound moved by its own body (6.4), loop nests whose trip counts multiply (6.1).
- Interface-dependent facts: module entry count (2.1), target features and limits (5.1), buffer aliasing (7.7).

Each NO or RENDERER row is a candidate for task D1 (rev 5, "WGSL legality as types"); the rows that are YES need only their closure test (task C1).
