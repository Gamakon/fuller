# WGSL kingdom — the function table

Generated by `gen_tables.py` from `functions.tsv`; edit the script, not this file.

A function is `class.instance` with a signature over duals. `<S.real>` stands for every real dual over scalar and vector lanes, `<S.c>` for any dual of form c, `<vecL.c>` for a vector of L lanes; the loader instantiates one row per legal dual, lanes equal across inputs unless the note says otherwise. The `naga` column is the IR node the row reads from and writes to; `composite` is a row the kingdom defines as a small WGSL function.

**Arity.** naga's select, fma, clamp, mix, smoothstep and extractBits take three operands. The decoders' limit is four (`K_MAX` = 4, `docs/PLAN_wgsl_kernel_reader.md` §2a, delivered in both crates 2026-10-08): the node is `(fn_id, first_child, ty_code, konst)` with children contiguous in level order and the arity from the kingdom's table; templates above four operands stay composed from two rows.
