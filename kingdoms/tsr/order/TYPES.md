## Duals

A dual is `shape.level`. It is an UPPER BOUND on the subtree under a slot: every leaf fits every dual, and a row's output is computed from the argument duals it asks for, so the true profile of what fills a slot is never above the declared one. Soundness: a gene that expresses has true order at most the ceiling and true depth at most 2. Completeness: a tree within both limits has an exact dual at every node, so every node is an existing row.

## Terminals

Every dual, ROOT included, has a `var` terminal (one per input column) and a `const` placeholder `?`. That is the polymorphic spelling of MultiTypedGEP.md section 1, and it satisfies the contract check "a terminal for every demanded type" (a bare leaf has order 1 and a type such as A21 cannot otherwise have a terminal).

## ROOT
